# Gathera

> A little office in another world.

A cosy 2D virtual office. You walk around a hand-built pixel workspace, and when
you get close to someone their video fades in and you can just talk. No meeting
links, no lobby, no scheduling. Walk over, say hello, walk away.

This is a complete, working application, not a scaffold.

---

## 1. What is actually in here

| Layer | Technology | Where |
| --- | --- | --- |
| World rendering | Phaser 3 | `src/game` |
| App shell and UI | React 18 + Vite + TypeScript | `src/ui`, `src/App.tsx` |
| Realtime presence | PartyKit (Cloudflare Durable Objects) | `party/server.ts` |
| Voice and video | Plain WebRTC, peer to peer mesh | `src/media` |
| UI state | zustand | `src/state/store.ts` |
| Art | Generated with Python + Pillow | `tools/` |

There is deliberately **no SFU**. Up to about eight people in one space, a mesh
is simpler, cheaper (free) and lower latency. See section 8 before you grow past
that.

## 2. Run it in five minutes

You need [Node.js 20 or newer](https://nodejs.org). Nothing else.

```bash
npm install
npm run dev
```

That starts two things at once:

- the web app on **http://localhost:5173**
- the realtime server on **http://127.0.0.1:1999**

Open the app, type a name, build an avatar, click **Step inside**.

**To test multiplayer properly**, open a second window in incognito mode and
join with a different name. Two normal tabs share a microphone and will confuse
you. Incognito is not optional.

## 5. The idea behind proximity

Three rules run the whole social layer. They live in `src/media/proximity.ts`.

**Who do I connect to?** If either of you is standing in a named zone, you
connect only to people in that same zone. Otherwise you connect to anyone within
4 tiles. Once connected you stay connected until you are 6 tiles apart. That gap
between 4 and 6 is deliberate hysteresis: without it, standing on the boundary
would reconnect the call several times a second.

**How loud are they?** Full volume within 2 tiles, silence at 6, and a smooth
cosine curve in between. Shared zone means full volume regardless of distance.

**How big is their video?** 200px within 2 tiles, shrinking to 120px at 4 tiles,
then the tile disappears and only their name plate remains. Video is part of the
world, anchored above their head, not a grid in a sidebar.

The seven zones are Work Floor, Meeting Room, Kitchen Nook, Lounge, Focus Booth,
Entrance and Your Desk. Meeting Room and Focus Booth are **private**: audio does
not leak out of them.

## 6. Project layout

```
gathera/
  party/server.ts        The realtime server. Presence, chat, signalling, host powers.
  public/assets/         Generated art. Do not hand edit; edit the generators.
  src/
    shared/              Types and constants shared by client and server.
    state/store.ts       All React state. One store, no context soup.
    net/socket.ts        The websocket. Reconnects, heartbeat, latency.
    media/               getUserMedia, one Peer per person, proximity maths.
    game/                Phaser. MainScene is the world; bridge.ts is the only seam.
    ui/                  Every React component. Presentational only.
    styles/              tokens.css is the design system. components.css uses it.
  tools/                 Python art generators.
```

**The one architectural rule:** React never reaches into Phaser and Phaser never
renders React. They talk through `src/game/bridge.ts` and nothing else. Phaser
runs at 60fps; if it triggered React renders the app would crawl. The bridge
throttles the world down to 5 updates a second before React ever hears about it.

## 7. Changing the art

Every sprite is generated by Python, so the palette is enforced by code rather
than by discipline.

```bash
pip install pillow
npm run art
```

- `tools/palette.py` is the single source of colour. Change a hex here and it
  propagates to every tile and every character.
- `tools/generate_art.py` builds the 52 tile tileset.
- `tools/generate_chars.py` builds 77 character layer sheets.
- `tools/generate_map.py` builds the office floor plan.

Characters are **composed at runtime** from layers (skin, bottom, shoes, top,
hair, accessory), not baked. That is why there are thousands of possible avatars
from 77 small files.

If you want to hand draw instead, the tileset is a plain 12 by 5 grid of 32px
tiles and the map is standard Tiled JSON. Open `public/assets/maps/office.json`
in [Tiled](https://www.mapeditor.org) and edit it directly.

### The rules that keep it looking right

1. Outlines are **warm dark brown** (`#3A211D`), never black. This one decision
   does more for the mood than anything else.
2. Every surface gets three tones: shadow, mid, highlight.
3. Light always comes from the upper left.
4. Shadows are sprites in the world, never CSS box shadows.
5. No pure black, no pure white, no cool grey anywhere.

## 8. Deploying

### The web app (Vercel)

```bash
npm run build
```

Deploy the `dist/` folder. Set one environment variable:

```
VITE_PARTYKIT_HOST=your-project.your-username.partykit.dev
```

### The realtime server (PartyKit)

```bash
npx partykit deploy
```

Free for individuals. The Durable Objects free tier covers roughly 100,000
requests a day, which is far more than a small team will ever use.

### TURN (only if calls fail)

About 10 to 15 percent of connections cannot go peer to peer directly, usually
corporate networks and strict NATs. Those need a relay.

Create a Cloudflare Realtime TURN key at
[dash.cloudflare.com](https://dash.cloudflare.com), then:

```bash
npx partykit env add TURN_KEY_ID
npx partykit env add TURN_KEY_API_TOKEN
```

The server mints short lived credentials per session and hands them to the
browser; the secret never reaches the client. 1000 GB a month is free. Without
these variables the app falls back to public STUN and still works for most
people. The Settings panel tells you which mode you are in.

## 9. Scaling honestly

A mesh means every person sends their video to every other person. At 8 people
that is 7 uploads each, which a normal connection handles. At 15 it will not.

The app caps you at 6 simultaneous peers (`MAX_PEERS` in `src/shared/config.ts`)
and always keeps the closest people, so a crowded room degrades gracefully
instead of collapsing. If you genuinely need 20 people talking at once you need
an SFU, and that is a real project, not a config change.

## 10. When something breaks

**Nobody appears.** Is the realtime server running? Check
http://127.0.0.1:1999. The top right of the app shows the connection state.

**I can see them but not hear them.** Press `` ` `` for the debug overlay. If a
peer sits on `connecting` forever, you need TURN (section 8). Chrome's
`chrome://webrtc-internals` shows exactly where it stalls.

**Everything is blurry.** Something disabled `pixelArt` in
`src/game/PhaserGame.tsx`. All three of `pixelArt`, `roundPixels` and
`antialias: false` must stay.

**The map is missing.** Run `npm run art`.

**Audio does not start.** Browsers block audio until you interact with the page.
Joining counts as an interaction, so this should not happen, but a hard refresh
fixes it if it does.

## 11. What is not built yet

Being straight with you about the edges:

- **No sitting or sleeping sprites.** Idle players fade and get a sleep icon
  instead of a sit animation. Adding real frames means extending
  `generate_chars.py`.
- **No in-app map editor.** Edit the map in Tiled or in the generator.
- **No screen sharing.** The plumbing is there (`replaceTrack` in
  `PeerConnection.ts`) but the UI is not.
- **Chat history is not persisted** across a full server restart.
- **Mobile works but is not the point.** Walking with a keyboard is the
  interaction; touch controls are not built.
